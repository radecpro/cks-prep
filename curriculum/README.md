# Curriculum planning

These are study checklists, not an exhaustive or versioned copy of the official syllabus. Before authoring each lab, map its requirements to the current [CNCF CKS curriculum](https://github.com/cncf/curriculum) and record the version or commit used. Confirm exam environment and rules with [Linux Foundation](https://training.linuxfoundation.org/certification/certified-kubernetes-security-specialist/). Domain weights are deliberately not frozen here.
